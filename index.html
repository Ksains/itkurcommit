Заполните карточку, добавьте один файл через Git и предложите его команде. Мы собрали весь путь здесь.

Что понадобится

Браузер, аккаунт GitHub и Git на компьютере. Запускать сайт у себя не нужно.

PR (Pull Request) — предложение добавить ваши изменения в общий репозиторий.

00ПодготовьтесьАккаунт GitHub и установка Git

Создайте аккаунт на GitHub ↗ и установите Git ↗. Попросите руководителя прислать ссылку на общий репозиторий.

Откройте терминал, в Windows подойдёт PowerShell. Проверьте установку:

Терминал · Проверка Git
git --version

Если впервые работаете с Git, настройте автора коммитов. Замените пример своими данными:

Терминал · Ваши данные
git config --global user.name "Ваше имя"
git config --global user.email "your-email@example.com"

Используйте почту аккаунта GitHub или адрес noreply из Settings → Emails. Если Git уже настроен, менять настройки не нужно. Если команда не найдена, перезапустите терминал после установки.

✓ Результат: аккаунт создан, Git готов к работе.

01Создайте свою рабочую копиюFork, скачивание и отдельная ветка

Откройте репозиторий по ссылке руководителя и нажмите Fork → Create fork. Это создаст вашу копию. В своём форке скопируйте HTTPS адрес из меню Code.

Замените ССЫЛКА_НА_ФОРК, ИМЯ_ПАПКИ и ВАШ_ЛОГИН своими значениями. Путь с пробелами заключите в кавычки.

Терминал · Рабочая копия
git clone ССЫЛКА_НА_ФОРК
cd ИМЯ_ПАПКИ
git switch -c onboarding/ВАШ_ЛОГИН

✓ Результат: проект на компьютере, вы в своей ветке.

02Расскажите о себеЗаполните форму и скачайте карточку

В форме ниже расскажите о себе. Если есть идея проекта, опишите её; этот раздел необязателен. Скачайте JSON и положите его в папку participants своего форка.

Имя файла должно совпадать с логином в нижнем регистре, например amir.json. Если браузер добавил к имени (1), удалите этот суффикс. Каждый добавляет только свой файл.

Форму заполняйте на этом сайте. Пока файл не принят в общий репозиторий, карточку видите только вы в предпросмотре.

Перейти к форме ↗

✓ Результат: ваш JSON лежит в папке participants.

03Сохраните и отправьте изменениеТри команды: add, commit и push

В терминале скачанной копии выполните три команды. Замените ВАШ_ЛОГИН своим логином.

onboarding/ВАШ_ЛОГИН — название ветки из шага 01. Это не папка: сам файл лежит в participants.

Терминал · Отправка карточки
git add participants/ВАШ_ЛОГИН.json
git commit -m "feat: добавить свою карточку"
git push -u origin onboarding/ВАШ_ЛОГИН

Коммит сохраняет изменение в истории Git. Push отправляет его в ваш форк на GitHub.

✓ Результат: карточка отправлена в вашу ветку на GitHub.

04Предложите карточку командеPull Request и проверка руководителем

На GitHub нажмите Compare & pull request. В base repository выберите общий репозиторий команды, а в head repository — свой форк и учебную ветку.

Во вкладке Files changed должна быть только ваша карточка. Создайте PR и отправьте ссылку руководителю.

Проверка запустится автоматически. Если она сообщит об ошибке, откройте Checks и исправьте свой файл. Повторите коммит и push в той же ветке: PR обновится.

✓ Результат: руководитель получил вашу работу на проверку.

А дальше — вы в команде
